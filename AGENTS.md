# ТЭЙЛ — лендинг

Этот репозиторий содержит восстановленный код лендинга, отдельный от Tail Middle. Перед правками прочитать README.md и docs/RESTORATION.md.

Редактируемые страницы и ресурсы находятся в public/. Сервер Node.js и SQLite — в server/. Внешних npm-зависимостей нет, требуется Node.js 24+.

После изменений логики выполнить `node scripts/check.mjs` и `node --test tests/server.test.mjs`. Изменения оформления проверять в браузере. Не добавлять в Git реальные ответы, выгрузки, базы, .env, ключи и журналы. Для браузерных проверок использовать отдельную тестовую базу через DATABASE_PATH и только искусственные ответы.

Не отправлять тестовые ответы на исходный сайт. Публикация коммита в GitHub не меняет сайт на 192.144.14.178; его развёртывание требует отдельного поручения. Клонированный внешний вид и тексты не являются подтверждением реального запуска платного сервиса или выполненной правовой проверки.
