## Движение

Одна закреплённая сцена возможностей на широком высоком экране, четыре состояния. Карточки позиций собираются к связи; раскрывается документ и сравнение; сектор радара проходит по сигналам; появляется диалог с основаниями и сохранённым ожиданием. GSAP 3.15.0 уже поставляется локально, новых зависимостей нет. Основные свойства — transform/opacity; небольшие маски используют clip-path. Нет автоматического цикла, движения текста при чтении или сетевого запроса за ИИ-ответом.

На узком/низком экране режим ручной. Четыре настоящие кнопки переключают сцены без прокрутки. Клавиатура и reduced motion дают мгновенную смену. Неактивные панели исключаются через aria-hidden/inert. GSAP matchMedia очищает pin и эффекты при смене режима. Боковой радар показывает новые названия разделов; на тёмном фоне меняет цвет подписи.

## Положение анкеты

Убрана явная scrollIntoView при переходе. Заголовок получает фокус с preventScroll. Минимальная высота формы сохраняет наибольший показанный вопрос и сбрасывается при изменении ширины; браузерная привязка страницы отключена, чтобы FAQ ниже анкеты не тянул экран при росте содержимого. Следующий вопрос доступен сразу, а прежняя сцена рождения свечи сохранена.

Измерение обычным кликом в отдельном статическом демо на 1440×1000: переход «Ситуации → Поиск ответа» 7364 → 7364 px, «Поиск ответа → Новости» 7364 → 7364 px; новая свеча в обоих случаях запускалась. Проверка физическим кликом нужна потому, что locator-инструмент сам прокручивает целевой элемент перед нажатием. Рабочая база ответов не используется для проверки.

Публичная версия остаётся статическим демо без отправки ответов. Исходная Node/SQLite-версия и API сохранены.
