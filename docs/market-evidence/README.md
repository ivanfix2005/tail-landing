# Состав Индекса МосБиржи: срез 2 ноября 2026

Проверено 3 ноября 2026 года по публичному ISS ПАО Московская Биржа. Последняя доступная торговая дата ответа — **02.11.2026**.

**44 бумаги, 41 уникальный эмитент (компания).** Это число посчитано по всей базе из трёх страниц ответа (20 + 20 + 4 строки), а не по первым 20 строкам или только крупнейшим акциям. Пагинация и общее число 44 сохранены в `analytics.cursor` каждого исходного ответа.

Обыкновенные и привилегированные акции одного юридического эмитента объединены в одну компанию:

| Бумаги | Эмитент | EMITTER_ID ISS |
| --- | --- | --- |
| SBER, SBERP | Сбербанк | 484 |
| SNGS, SNGSP | Сургутнефтегаз | 1406 |
| TATN, TATNP | Татнефть | 852 |

Эти пары дополнительно сверены с `EMITTER_ID` в официальных карточках ценных бумаг; исходные шесть JSON находятся рядом. Остальные 38 строк принадлежат разным эмитентам. Группу компаний не объединяли в одно юридическое лицо.

Пересчёт: **44 − 3 = 41**. Для фразы с «более чем» корректно **«более чем 40 компаниями»**; фраза «более чем 41» означала бы минимум 42 и была бы неверной для этого среза. Точное число и дата могут быть показаны рядом: «41 компания · 44 бумаги · срез 02.11.2026».

## Логотипы

В `public/company-logos/` находятся восемь оригинальных PNG: ЛУКОЙЛ, Сбербанк, Газпром, Яндекс, Татнефть, Норникель, X5 и НОВАТЭК. Все восемь компаний есть в сохранённом составе IMOEX. Логотипы взяты из публичного CDN инвестиционного приложения Т-Банка и визуально проверены, исходные байты не менялись. URL, SHA-256, дата и статус лицензии каждого файла — в `public/company-logos/manifest.json`.

Путь с историческим идентификатором X5 служит только адресом ресурса в CDN, а не текущим ISIN бумаги. Открытая лицензия на товарные знаки не установлена; они используются для узнаваемости эмитентов и не должны обозначать партнёрство, интеграцию или одобрение ТЭЙЛ компаниями.
