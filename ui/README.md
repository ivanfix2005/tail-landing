# Анимированные преимущества ТЭЙЛ

`benefits.tsx` и `benefits.css` — собственные сцены ТЭЙЛ: событие связано с LKOH, проверка формулировки документа, изменение статуса. Они монтируются один раз в `#benefits-island`. Остальные разделы, опрос и сервер остаются на обычных HTML/CSS/JS.

`stageshow-kit/` — неизменённая копия kit из [benjitaylor/skills, stageshow](https://github.com/benjitaylor/skills/tree/802057409787133703c56001080169e347305572/stageshow), коммит `802057409787133703c56001080169e347305572`, получена 03.11.2026. LICENSE и NOTICE сохранены. `reference/static-card` и `reference/payout-flow` — исходные эталонные примеры из того же коммита для сравнения; в рабочий bundle не импортируются. Их первоначальные относительные импорты указывают на структуру исходного навыка.

Сборка: `npm ci --ignore-scripts`, затем `npm run build:ui`. esbuild использует поставляемый npm платформенный бинарный пакет. Результат — `public/components/benefits.js` и `benefits.css`; они сохраняются в репозитории, поэтому запуск сервера, Docker и файл запуска Windows не требуют сборки или установки npm-пакетов. Лицензии Stageshow, React, React DOM и Lucide включаются непосредственно в JS bundle. Версии закреплены в package-lock.json.

Композиция имеет отдельную компактную сцену шириной 300 px. На мобильном история вертикальная, важная строка и сумма не обрезаются. Все сцены `play="once"`, имеют законченный poster и кнопку повторного просмотра. Курсор использует измеряемые именованные цели `watchlist-next` → `lkoh-event`; на пустом месте нет щелчка.

Проверка через CUA описана в `docs/stageshow-refinement/REHEARSAL.md`. Headless film из навыка не запускался.
